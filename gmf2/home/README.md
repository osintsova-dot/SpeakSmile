# «Урок дома» · Give Me Five! 2

Самостоятельные уроки для пропустивших занятие (телефон, 15–25 минут). Движок общий с `gmf1/home` (см. его README): колода слайдов, пул 4 Audio для iOS, надёжный переход `go()` (snap off + fallback), `#jserr`, кнопка «Скопировать ссылку», отметка «Я сделал» → `/home-done` на воркер.

Сборка Starter: `scratchpad/g2/build.py` + `lesson_st1/2/3.py` (CSS берётся из gmf1/home/st-l1, st-l2, st-l3 + блок GMF2). Медиа Macmillan: `Методбаза/курсы/GMF2/media-macmillan/<Unit>/` (аудио Tap&Teach zip, мультик MASTER.mp4, тесты). Флэшкарты L2: карточка N = страница PDF 2N+3 (погода — повёрнута на 90°). PB pdf-страница = страница учебника; AB pdf-страница = страница тетради + 1.
