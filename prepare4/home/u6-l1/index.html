1some / any · much / many · a lot of · a few / a little

Tap a sentence to hear it.Student’s Book стр. 38, упр. 1–5. Все примеры — из статьи.

some / any

some — в утверждениях, any — в отрицаниях и вопросах.

многоmany · much · a lot of

many + исчисляемые (cars, people), much + неисчисляемые (petrol, time). В утверждениях обычно a lot of — подходит ко всем.

There is much traffic → There is a lot of traffic.

малоa few · a little

a few + исчисляемые (toys), a little + неисчисляемые (light). В отрицаниях — not much / not many.
