# «Урок дома» · Get Involved! A2 (GIA2)

Самостоятельные занятия для пропустивших пару (телефон, 25–30 минут), 12–14 лет. Движок и тема — как у GIA1 (`home-lesson-tools/gia1/u2/common_u2.py` → копия `home-lesson-tools/gia2/common.py`, тема `gia_theme.css`, `/home-done`, `const LESSON='gia2-…'`). Сетка — КТП `Методбаза/курсы/GetInvolved/A2/КТП-GetInvolved-A2.txt`: Starter = пары 1–4 (st-l1…st-l4), Unit 1 = пары 5–12 (u1-l1…u1-l7 + u1-test). Student's Book pdf = страница книги + 1; Workbook pdf = страница + 1.

**Медиа — оригинал Macmillan** (`Методбаза/курсы/GetInvolved/A2/media-macmillan/`): реплики/слова нарезаны из SB tracks 1–12, 59–60, WB 1–2 (whisper `ws.py` + выравнивание + «долины» энергии и silencedetect, проверка повторным whisper — `gia2/verify.py`); видео Vocabulary / Real-world speaking / Project — `video.mp4` (h264 960×540, faststart, 5–10.7 МБ) с постером `img/video.jpg` в u1-l1 / u1-l6 / u1-l7; реплики диалога Real-world speaking и причины из Project video вырезаны из звука видео. Edge TTS — только то, чего нет в записях: слова семьи / классных предметов / глаголов действия (Starter), тексты чтения без аудио (семьи стр. 8, Chinese student стр. 13, блог Алтина стр. 20), примеры-конструкции и вопросы для говорения. Картинки — кропы SB 200 dpi и теста. Ключи — SB / WB answer keys, Teacher’s Book (silent letters), Progress test AK.

Сборка: `~/Проекты с Claude/home-lesson-tools/gia2/` — `common.py` (движок + реестр `S()` оригинальных реплик и `T()` TTS), `st_l1…st_l4.py`, `u1_l1…u1_l7.py`, `u1_test.py`, `build.py [модули] --tts --cut`, `verify.py`, `crop.py`, `index_gen.py` (главная: перестраивает только плашки st и u1). Проверка: `COURSE=gia2 node chinese-course/tools/gia_check.mjs <port> <страницы> --shots`.

- **st-l1** All around the world (SB 6–7): 14 стран+национальностей (трек 1), таблица, ударение, World Quiz, be ’re/’s/aren’t/isn’t, Yes/No + краткие ответы, слова по буквам (трек 2), гласные в предметах класса, команды учителя ↔ картинки (трек 3), 4 разговора Tom/Kim/Ross ↔ картинки A–D (трек 4: 1C 2A 3D 4B), Wh- questions.
- **st-l2** Families (SB 8–9): Male/Female/Both, родство, 3 описания семей ↔ фото (1C 2D 3A), найди 12 слов, my/his/their, ’s/s’, Who is it? (ex 1: 1B 2J 3C 4E; трек 5: 1K 2H 3G 4A 5D), have got, Brain teaser (nine).
- **st-l3** What can you do? (SB 10–11): 10 глаголов ↔ фото, звуковые сценки (трек 6), can-таблица, предложения, Can you…? о себе, Test yourself!, гонка по учебнику.
- **st-l4** Starter round-up: квиз 12, «послушай и выбери» по оригинальным кускам, лесенка, перевод, правописание, speaking, досье, Я могу.
- **u1-l1** (SB 12–13, WB 4): 21 daily routine (трек 11), утро/день/вечер, факты на карте, My typical day ↔ картинки (A2 B5 C6 D1 E3 F4), время, at/in/on, видео Japanese school life + вопросы, WB 4 ex 3.
- **u1-l2** (SB 14–15, WB 8): фото A–J ↔ действия, порядок дня, predicting, статья (трек 7) по абзацам, T/F, complete, Word work, critical thinking, WB reading (WB трек 1) + краткие ответы.
- **u1-l3** (SB 16, WB 5): present simple + / −, -s/-es/-ies, ex 4, сделать правдой, Hogwarts (трек 8, предложение звучит после заполнения), Brain teaser (Tom 8:45 chess · Ana 9:15 music · Sara 8:00 dance), WB Olivia.
- **u1-l4** (SB 17, 116, WB 6): 17 предметов (трек 12), расписание и группы, отрывки уроков (трек 9), silent letters (треки 59–60), Ansa (трек 10) + T/F (true 2, 4), любимый день, WB отчёт и посты.
