## 4. Грабли
- `[hidden]{display:none!important}` обязателен при `.btn{display:inline-flex}`.
- iOS-звук (актуально с 2026-10-12, все уроки u2-l1…l5): **пул из 4 разблокированных Audio** (приём html5-пула howler.js). Старая схема «на первое касание `load()+play()/pause()` для КАЖДОГО из 60 кэшированных элементов» на iPhone через VPN молчала: все файлы грузились разом, нужный не успевал стартовать, а 4-секундный сторож его глушил. Теперь `unlock()` на первое касание создаёт 4 пустых `new Audio()` и вызывает `load()`; `getNode(id)` берёт свободный элемент пула (не `current`) и ставит `src='audio/'+id+'.mp3'` по требованию; `isCur(id)` вместо `current===cache.x`; `play(id,onend,at)` — перемотка `at` после `loadedmetadata` (песня по строкам); сторож: стоп по зависанию 4 с только ПОСЛЕ того, как звук реально пошёл, до старта ждём 25 с, плюс `a.error`. Никакого `preload`-списка файлов и `snd()` больше нет — копировать блок `const POOL…function stopAll` из `u2-l5/index.html` (в u2-l3 в `stopAll` добавлена пауза видео). В headless Chrome страница грузится мгновенно и `--dump-dom` выходит до таймеров — для проб вставлять `<img src="http://10.255.255.1/hang.png">`, чтобы задержать `load`.
- Gemini TTS на VPS: `gemini-2.5-flash-preview-tts` отдаёт HTTP 429 примерно после 30–35 реплик за прогон — скрипт пропускает элемент после 5 попыток; хвост догенерировать тем же скриптом с моделью `gemini-2.5-pro-preview-tts` (`gen_pro.py`). Запуск только отвязанно: `nohup setsid python3 gen_pro.py > log 2>&1 < /dev/null &`; SSH к aeza рвётся — цикл с `ConnectTimeout=25`.
- (история) до 2026-10-12 было: iOS: разрешение на звук выдаётся КАЖДОМУ Audio-элементу отдельно и только внутри жеста; muted play ничего не разблокирует (поэтому «Слушать всё» молчало после 1-й реплики). Рабочий `unlock()` на первое касание: для каждого кэшированного элемента `load(); play().catch(); pause(); currentTime=0` (приём howler.js); на карточке «знаю/не знаю» кнопка «Послушать» и спереди. ⚠️ Гонка: колбэк unlock приходит позже и может поставить на паузу уже играющую реплику или оставить её muted (реплики «перескакивают/зависают», 2026-10-11) — в колбэке `if(a===current) return`, а в `play()` всегда `a.muted=false` перед стартом. Плюс сторож: весь звук идёт через `start(a,onend)` — интервал 200 мс следит за `currentTime`; реплика считается законченной по `ended`, по достижению `duration`, или если позиция не двигается 4 с (iOS иногда «играет» молча и не шлёт `ended` — цепочки «ответ → следующий вопрос» зависали). На `onended` одном полагаться нельзя.
- Гейта пока нет (только noindex). Когда уроков станет несколько — гейт по коду семьи как `chinese/gate.js` + `lessons.json` с датами.
- Длинные слова (computer game) в мемо: `word-break:keep-all`, перенос только по пробелу.
- Слайд = flex-колонка: детям `.slide>*{flex-shrink:0}` обязательно, иначе при переполнении блоки сжимаются и облачка/лоток наезжают на кнопки (вылезло на iPhone в L3). Низ слайда `padding-bottom: calc(118px + safe-area)`, чтобы навигация не закрывала последний ряд.
- Медиа Macmillan (zip аудио, мультик истории) хранить в `Методбаза/курсы/GMF1/media-macmillan/U{N}/`.
- Следующий шаг после 2–3 уроков руками — генератор: `lessons/u{N}-l1.json` → index.html (данные уже вынесены в константы в начале `<script>`).
