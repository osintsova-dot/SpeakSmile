# Тест на уровень · 1–4 класс (`/test/kids/`)

Адаптивная цепочка диагностических тестов Macmillan **Give Me Five!** (Diagnostic Test Level N = что ребёнок должен знать *до* курса GMF N, т. е. материал GMF N−1).

## Логика
- Анкета родителя: имя и фамилия, класс 1–4, телефон/ник (необязательно), «учил английский?», «что уже пройдено» (по умолчанию — по классу).
- «Нет, с нуля» → сразу результат **GMF 1 с нуля** (тест не проходит, результат всё равно отправляется).
- Старт: 1–2 класс → L2, 3 класс → L3, 4 класс → L4 (родитель может выбрать GMF 1/2/3/4 пройден → L2/L3/L4/L5).
- Порог **≥ 70 %** баллов. Сдал → следующий уровень (до L5). Не сдал → шаг вниз (до L2), пока не сдаст. Максимум **3 теста**, между ними экран-перерыв (можно «Закончить»).
- Итог = самый высокий сданный N → «GMF N»; L5 → «Get Involved A1+ (после GMF 4)»; ничего не сдано и L2 не сдан → «GMF 1 (продолжающие)».
- Результат: `SSPlace.send({test:'kids', …})` из `/assets/place.js` — один раз (флаг `sent` в localStorage). Не ушло → «Покажите этот экран администратору», place.js сам дошлёт при следующем открытии.
- Прогресс — localStorage `ss_kids_v1` (экран «Продолжить?»).

## Файлы
`index.html` (разметка) · `kids.css` · `kids.js` (движок) · `data.js` (все вопросы и ключи) · `img/*.webp` (кропы из PDF тестов, 150 dpi; дома L3 — 300 dpi) · `audio/*.mp3` (64 kbps mono, по одному клипу на вопрос).

## Что вошло (каждое задание: пример + 5 вопросов × 2 балла)
| Тест | Задания | Макс |
|---|---|---|
| L2 | 1 Listen & tick (Track 02) · 2 Listen & circle Bill/Bob (Track 03) · 3 Read & circle · 4 Look & write → **выбор предложения** (I love/like/don’t like) · 5 Look & write → **выбор слова из 3** | 50 |
| L3 | 1 Listen & number (Track 02 → «найди картинку» из 6) · 2 Listen & tick (Track 03) · 3 Match Q&A → выбор ответа из a–f · 4 Houses A/B · 5 What are they doing? → **выбор предложения из 3** | 50 |
| L4 | 1 Listen & tick a/b/c (Track 02) · 2 Read, listen, true/false (Track 03) · 3 Parade yes/no · 4 Read & circle · 5 Look, read & write → **выбор ответа из 3** | 50 |
| L5 | 1 Listen & circle · 2 Listen true/false · 3 Read & circle · 4 Cloze «A look into the future» | 40 |

**Пропущено:** Speaking во всех тестах; L3 №6 (directions по карте); L4 №6 (Write answers for you); L5 №5–6 (личные ответы, эссе) — не проверяются автоматически.
Переделанные задания (письмо → выбор) — дистракторы придуманы нами, верный ответ = официальный ключ (в L4 №5 — «suggested answers» ключа).

## Аудио
- L2–L4: официальные дорожки `0{2,3}_GMF{N}_TR_DiagnosticTest_Act{1,2}.mp3` (Resource Centre, `Tests/Audio_Files__Standard_and_Higher_Level_Tests/`), порезаны по паузам (≥ 2,5 с) на 6 клипов `l{N}a{1,2}_{1..6}.mp3`, проверено по whisper.
- **L5: аудио Macmillan недоступно (L5 нет на полке, CDN 403)** → озвучено Edge TTS (Sonia/Ryan; Марк = Ryan +18 Hz) по audioscript из официального Answer Key L5. Клипы `l5a1–6`, `l5b1–5` (монолог Марка разбит по [pause]).
- Исходники и ключи сохранены в `Методбаза/курсы/GMF{2,3,4,5}/tests/` (скачаны 31.10.2026: L3 и L5 Answer Key, 6 mp3).

## Ключи
Все ключи — из официальных Answer Key L2/L3/L4/L5 (L5 Answer Key нашёлся на CDN по прямой ссылке). Самодельных ключей к листенингу нет.
Сборка (скрипты в scratchpad сессии): `crop.py` (кропы), `cut.py` (нарезка аудио), `tts_l5.py` (L5 TTS); проверка — `serve/harness.html` (заглушка place.js, сценарии логики) и `shot.html` (скриншоты 390×844).
